# Анализ тональности отзывов через GigaChat API

## Описание задачи

Скрипт читает CSV-файл с текстами отзывов, отправляет каждый из них в языковую модель GigaChat и получает в ответ структурированный JSON с двумя полями:

- `sentiment` — тональность отзыва (например: `positive`, `negative`, `neutral`)
- `topic` — тема отзыва (например: `доставка`, `качество товара`, `обслуживание`)

Результаты сохраняются в файл `result.json`.

## Требования

- **R** версии 4.1 и выше
- Пакеты R: `httr2`, `jsonlite`, `uuid`
- Аккаунт в [GigaChat API](https://developers.sber.ru/portal/products/gigachat) с активным ключом авторизации

Установка пакетов (один раз, в консоли R):

```r
install.packages(c("httr2", "jsonlite", "uuid"))
```

## Структура файлов

```
project/
├── main.R                 # основной скрипт
├── data.csv               # входной файл с отзывами
└── result.json            # выходной файл (создаётся автоматически)
```

## Подготовка входных данных

Файл `data.csv` должен быть в кодировке **CP1251** и содержать колонку `review` с текстами отзывов.

Пример `data.csv`:

```
review
Отличный товар, доставили быстро!
Качество оставляет желать лучшего.
Всё хорошо, но упаковка была повреждена.
```

## Настройка и запуск

1. Откройте файл `main.R`.
2. Вставьте ваш ключ авторизации в переменную `AUTH_KEY` (строка 4). Ключ можно найти в [личном кабинете](https://developers.sber.ru/studio), он заканчивается на `==`.
3. При необходимости измените `MAX_REVIEWS` — максимальное количество обрабатываемых отзывов (по умолчанию 50).
4. Запустите скрипт:

```bash
Rscript main.R
```

Или через RStudio: откройте файл и нажмите **Source**.

## Возможные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Не удалось получить токен. Статус: 401` | Неверный ключ авторизации | Проверьте `AUTH_KEY` в скрипте |
| `Ошибка: could not resolve host` | Нет доступа к серверу Sber | Проверьте VPN / интернет-соединение |
| `parse_error` в JSON | Модель вернула неожиданный формат | Безопасно игнорировать; отзыв помечается как необработанный |
